Billing FAQ

How does the free trial work?

Investor, Agent and Pro start with 7 days free. You add a card at checkout and can cancel any time before the trial ends from Plan & Settings. You will not be charged until day 8.

What is a "live property pull"?

A lookup that hits a paid data provider (owner, tax history, value and rent estimates). Re-opening a property you already pulled, or running more analyses on it, does not count. Searching the Deal Finder does not count either.

What happens when I hit a monthly limit?

Nothing breaks. You can keep analyzing; extra reports are $9 each on paid plans, or you can upgrade mid-cycle and Stripe prorates the difference.

Can I switch markets?

Investor and Agent include one market. You can change it once per billing cycle from settings, or add another market for $39/month. Pro includes every live market.

What is an exclusive ZIP?

Agents can lock a ZIP code so no other Parcelyst agent sees likely-to-list scores there. One agent per ZIP, first come first served, $99/month per ZIP.

Do you offer brokerage or team pricing?

Yes. Pro covers 3 seats. For brokerages, white-label reports and API access, contact us below.
