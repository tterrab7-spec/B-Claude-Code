# DirtBid video audio

Offline, deterministic music and sound-effect rendering in plain Node.js (no native audio deps).

```
npm run audio        # = node tools/audio/sfx.mjs && node tools/audio/music.mjs
```

## Files

| file | what |
| --- | --- |
| `dsp.mjs` | Small DSP toolkit: wav read/write (16-bit dithered or float32), mp3 decode via the Remotion ffmpeg binary (cached as wav in `.cache/`), sampled `Instrument` with pitch-shifting playback, ADSR, RBJ biquads (low/high-pass, shelves, peak, band-pass), Freeverb-style reverb, soft-knee compressor, true-peak look-ahead limiter, soft saturation, LUFS measurement (ffmpeg `loudnorm`). |
| `music.mjs` | The score. Renders `public/audio/music.wav` (62 s, stereo, 44.1 kHz, -18 LUFS integrated, -1 dBTP) and prints a bar-by-bar arrangement summary. `DEBUG=1` also prints per-bus levels and where the limiter works. |
| `sfx.mjs` | Renders the UI/foley effects into `public/audio/sfx/` (peak -3 dBFS, click-free) plus `index.json` with durations. |
| `timeline.json` | Scene and voice-over cue times the score is written against (generated by `print-timeline.mjs`). |
| `.cache/` | Decoded sample wavs and the pre-master; safe to delete (git-ignored). |

## How the score is built

`music.mjs` is a tiny sequencer: helpers (`note`, `pick`, `strum`, `mel`, `roll`, `pad`, `kick`, `shaker`, `wb`) push events onto
instrument buses, each bus is rendered from the samples, EQ'd / compressed / saturated, summed with two reverb sends
(a short room and a longer hall), gated for the drop-out at 23.85-24.05 s, bus-compressed, gain-calibrated against ffmpeg's
loudness meter, and finally limited.

The bar grid is anchored to two picture moments so the music lands exactly on them:

```js
const HIT = 24.35;    // D major chord hit that opens the "turn"  (bar 11, beat 1) = turn scene start + 0.5
const FINAL = 58.35;  // final cadence                          (bar 27, beat 1)
const BEAT = (FINAL - HIT) / 60;  // 60 beats between them -> 105.9 BPM
```

Three bars change meter so the section downbeats also land on the cuts: bar 6 is 3/4 (a breath under the stakes cut),
bars 12 and 19 are 2/4 (the fills into product and partners). `METER(bar)` holds this; `T(bar, beat)` walks the map.

Sections: hook (bars 0-1, C major) -> problem (2-5, A minor) -> stakes (6-10: 3/4 Am breath, rising bass A B C D E F F# G#,
stutter on A7, hard drop-out 23.85-24.05) -> turn (11-12, lift to D major, 2/4 fill) -> product (13-19, groove, "ta-da" glock accent
at 37.95 under "within five percent", 2/4 fill) -> partners (20-23) -> cta (24-26) -> final chord (27, 58.35) ringing to silence by 61.4 s.

### Changing the key or tempo

* **Key**: set `KEY_SHIFT` (semitones) at the top of `music.mjs`; every pitch goes through it. `+2` gives D major / B minor
  in the first half and E major after the lift. Anything within about ±3 semitones keeps the guitar and bass in a natural range.
* **Tempo**: the tempo is derived from `HIT` and `FINAL`. To change the tempo without moving those anchors you would need to
  change the number of beats between them (`BEATS_HIT_TO_FINAL`, currently 60); to move the hit or the ending, change the anchors and
  the tempo follows. `BEATS_BEFORE_HIT` (43) places bar 0; the odd-meter bars are in `METER`.
  Swing per section is in `swingFor(bar)`.
* **Loudness**: `LUFS_TARGET` and `CEILING_DB`. The render measures itself with `ffmpeg loudnorm` and iterates until it is
  within 0.3 LU of the target.
* **Balance**: per-bus gain, reverb sends and timing jitter live in the `BUSES` table.
